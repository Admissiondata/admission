# admission

## નવરાત્રી ગરબા પાસ ૨૦૨૬

Web app — રજીસ્ટ્રેશન ફોર્મ, પાસ જનરેશન/પ્રિન્ટ અને વ્યવસ્થાપન. ડેટા **SQLite** database (server) માં રહે છે, એટલે બધા કમ્પ્યુટર થી એક જ ડેટા સાથે કામ થાય છે.

### ચલાવવા

```
pip install flask
npm run navratri
```

પછી browser માં `http://localhost:5000` ખોલો. એ જ WiFi network ના બીજાં કમ્પ્યુટર થી `http://<આ કમ્પ્યુટર નો IP>:5000` ખોલી શકાય (ઉ.દા. `http://192.168.1.10:5000`). IP જાણવા `hostname -I`.

### સેટિંગ્સ (વ્યવસ્થાપન → ફોર્મ અને પાસ સેટિંગ્સ)

- **ટાઈટલ / હેડિંગ** – ફોર્મ અને પાસ નું નામ બદલો
- **સબ-ટાઈટલ** – મંડળનું નામ
- **સરનામું** – મંડળનું સરનામું (ફૂટરમાં છપાય)
- **મહોત્સવ તારીખ** – થી / તા (ફોર્મ અને પાસ પર)
- **લોગો** – ફોર્મ ઉપર દેખાય તેવો લોગો અપલોડ કરો

ફોર્મમાં હવે ખેલૈયાનો **ફોટો** અને **આધાર કાર્ડ નંબર + ફોટો** પણ મુકી શકાય છે (બંને વૈકલ્પિક). પાસ પર ફોટો છપાય છે. બધી તારીખો **DD-MM-YYYY** ફોર્મેટમાં દેખાય છે.

### એડમિન PIN

ડિલીટ / બધું સાફ / એડિટ / સેટિંગ્સ / પુનઃસ્થાપિત કરવા એડમિન PIN જોઈએ. ડિફૉલ્ટ PIN: `1234`. બદલવો હોય તો:

```
ADMIN_PIN=your_secret npm run navratri
```

### એપી આઈ (API)

| રૂટ | કામ |
|------|-----|
| `POST /api/register` | નવું રજીસ્ટ્રેશન (number server આપે; ફોટો/આધાર સાથે) |
| `GET /api/registrations` | યાદી (`?q=` થી શોધ) |
| `GET /api/registrations/<no>` | એક પાસ (ફોટો/આધાર સાથે) |
| `PATCH /api/registrations/<no>` | સરનામું / તારીખ / નામ વગેરે એડિટ (PIN) |
| `DELETE /api/registrations/<no>` | ડિલીટ (PIN) |
| `POST /api/clear` | બધું સાફ (PIN) |
| `GET /api/settings` | સેટિંગ્સ (ટાઈટલ, તારીખ, લોગો વગેરે) |
| `POST /api/settings` | સેટિંગ્સ સેવ (PIN) |
| `POST /api/logo` | લોગો અપલોડ (PIN) |
| `GET /api/stats` | આંકડા |
| `GET /api/export.csv` | CSV ડાઉનલોડ |
| `GET /api/export.xlsx` | Excel ડાઉનલોડ (list-wise) |
| `GET /api/export.json` | JSON બેકઅપ (PIN) |
| `POST /api/import` | બેકઅપ પુનઃસ્થાપિત (PIN) |
| `GET /api/next` | આગામી પાસ નંબર |

ડેટા ફાઈલ: `navratri_data.db` (delete કરીને ફરી શરૂ કરી શકાય).
